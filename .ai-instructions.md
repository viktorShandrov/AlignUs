# AI Development Workflow Rules

1. **Commit Policy:** Every task completion MUST end with a Git commit.
2. **Commit Message Format:** Use Conventional Commits:
   - `feat(scope): short description`
   - `fix(scope): short description`
   - `refactor(scope): short description`
3. **Execution:** 
   - After writing code, run tests if applicable.
   - Stage changes: `git add .`
   - Create commit: `git commit -m "<type>(<scope>): <description>"`
   - Push to origin: `git push`
4. **Validation:** Always verify the diff before committing. If a commit fails, report the error and fix it immediately.
